This folder contains C programs that demonstrate the use of relational operators and logical operators to compare values and make decisions.

📌 Programs

1. Admission Eligibility Checker

This program checks whether a student is eligible for admission based on their age and marks.

Conditions for eligibility:

- Age must be 18 or above.
- Marks must be 75 or above.

Admission is successful only when both conditions are satisfied.

Condition Used:

if (age >= 18 && marks >= 75)

Concepts Used:

- "if / else" statements
- Logical AND ("&&") operator
- Relational operators
- User input using "scanf()"
- Comparison of multiple conditions

2. Relational Operators in C

This program demonstrates how relational operators compare two integer values.

Values Used:

int a = 20;
int b = 10;

Operators Used:

Operator| Meaning
"=="| Equal to
"!="| Not equal to
">="| Greater than or equal to
"<="| Less than or equal to

Relational expressions return:

- "1" when the condition is true.
- "0" when the condition is false.

Concepts Used:

- Integer variables
- Relational operators
- Comparison of two values
- True and false results in C

🧠 What I Practiced

- Comparing values using relational operators
- Understanding the difference between "==" and "!="
- Using ">=" and "<=" to check conditions
- Combining multiple conditions using "&&"
- Understanding true ("1") and false ("0") results
- Applying operators to real-world problems
- Using conditional statements to make decisions

🎯 Goal

The main goal of these programs is to understand how relational and logical operators work in C and how they help build conditions for decision-making, rather than simply memorizing the syntax.
