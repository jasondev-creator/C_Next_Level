# Relational Operators in C

This program demonstrates the use of **relational operators** in the C programming language.

## 📌 About

Relational operators are used to compare two values.  
The result of a comparison is:

- `1` → True
- `0` → False

In this program, two integer values are compared using different relational operators.

## 🧑‍💻 Operators Used

| Operator | Meaning |
|----------|---------|
| `==` | Equal to |
| `!=` | Not equal to |
| `>=` | Greater than or equal to |
| `<=` | Less than or equal to |
