# Character, Integer and Float

## Concepts
- `char[]` → stores a string
- `int` → stores whole numbers
- `float` → stores decimal numbers

## Format Specifiers
- `%s` → string
- `%d` → integer
- `%f` → float

## Key Learning
Different data types are used to store different kinds of values,
and `printf()` uses the appropriate format specifier to display them.
