# 04 - Decision Making

This folder contains C programs that practice **decision-making and conditional logic** using `if`, `else if`, `else`, comparison operators, logical operators, and the modulus operator.

## Programs

### 1. Character Type
Checks whether an entered character is:
- Uppercase
- Lowercase
- Number
- Special symbol

**Concepts Used:**
- `char`
- `scanf()`
- Character comparisons
- `if / else if / else`
- Logical operators

---

### 2. Triangle Type
Takes three side lengths and determines whether the triangle is:
- Equilateral
- Isosceles
- Scalene

**Concepts Used:**
- Integer variables
- Comparison operators
- Logical OR (`||`)
- `if / else if / else`

---

### 3. Leap Year Checker
Checks whether a given year is a leap year.

The program uses the leap-year rules involving divisibility by:
- 400
- 4
- 100

**Concepts Used:**
- `%` (Modulus)
- Comparison operators
- Logical AND (`&&`)
- Logical OR (`||`)
- `if / else`

## What I Practiced

- Building conditions logically
- Combining multiple conditions
- Using comparison operators
- Using logical operators
- Understanding `%` for checking divisibility
- Testing programs with different inputs and edge cases

## Goal

The main goal of these programs is to improve **problem-solving and logical thinking in C**, rather than simply memorizing code.
